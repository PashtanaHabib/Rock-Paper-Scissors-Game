
# Rock Paper Scissors Game ✊📄✂️

## 📌 About The Project

Rock Paper Scissors is a practice project developed to improve JavaScript programming skills and gain practical experience with fundamental JavaScript concepts.

This project is built using **HTML, CSS, and JavaScript**. It allows users to play the classic Rock Paper Scissors game against the computer.

The main purpose of this project is to practice JavaScript functions, conditional statements, DOM manipulation, random number generation, and other essential programming concepts.

## ⚙️ JavaScript Functions Used

The following custom functions are implemented in this project:

| Function | Description |
|---|---|
| `generateHand()` | Randomly generates a hand for the computer. |
| `check(userHand)` | Checks the user's choice against the computer's choice. |
| `nextLevel()` | Increases the score and starts the next round. |
| `endGame()` | Ends the current game round and resets the score. |
| `setCpuHand(hand)` | Displays the computer's selected hand image. |
| `setScore(text)` | Updates the score displayed on the page. |
| `playCorrect()` | Plays the correct-answer sound. |
| `playInCorrect()` | Plays the incorrect-answer sound. |
| `setBgColor(color)` | Changes the background color of the main section. |

## 🔧 JavaScript Methods Used

| Method | Description |
|---|---|
| `Math.random()` | Generates a random number between 0 (inclusive) and 1 (exclusive). |
| `Math.floor()` | Rounds a number down to the nearest integer. |
| `document.getElementById()` | Selects an HTML element by its ID. |
| `document.querySelector()` | Selects the first HTML element matching a CSS selector. |
| `play()` | Plays an audio file. |

## 📌 Other JavaScript Properties & Features

## 🎮 How to Play

1. Open the game in your browser.
2. Choose Rock, Paper, or Scissors.
3. The computer randomly selects its hand.
4. The game checks the result.
5. Earn points by winning rounds.
6. If you lose, your score resets.
